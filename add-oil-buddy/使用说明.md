# Buddy 加油站每日积分自动领取 · 使用说明

一个 WorkBuddy Skill：让 WorkBuddy 自动建一个「每天定时领取 Buddy 加油站每日积分」的定时任务。到点后自动打开客户端里的加油站、点领取、确认结果并记日志，无需你守着。

## 开箱即用：把下面整段发给 WorkBuddy

> 这是**唯一需要你做的事**。复制 `┌ 引导 PROMPT` 到 `└ 引导 PROMPT` 之间的全部文字，把里面的 `【压缩包路径】` 换成你实际放 zip 的位置、`【时间】` 换成你想要的时间（不想要就写 `12:00`），然后发给 WorkBuddy。剩下的（装 skill、装 Python、装 Pillow、建任务）全部由它自动完成。

## 这段 prompt 会替你做什么

| 步骤 | 自动完成的内容 |
|---|---|
| 安装 | 解压 zip → 复制到 `%USERPROFILE%\.workbuddy\skills\` → 已有则备份覆盖 |
| Python | 优先用本机已有的 Python（含 WorkBuddy 自带的隔离 venv），无需你另装 |
| Pillow | 缺了就 `python -m pip install Pillow` 自动装好 |
| 任务 | 用 WorkBuddy 内置 automation 工具建好每天定时任务 |

真正需要你准备的只有两样：**一个能运行的 WorkBuddy** + **上面那段 prompt 里填对压缩包路径和时间**。

## 到点后会发生什么

1. 弹出「5 分钟倒计时」提醒窗：可点 **立即领取** 马上开始，或让它自动到点执行。
2. 脚本置顶 WorkBuddy 窗口 → 点头像菜单 → 进入 Buddy 加油站 → 点「领取」→ 检查按钮颜色确认 → 关窗、鼠标归位。执行段约 3~5 秒。
3. 结果写入 `%USERPROFILE%\.workbuddy\skills\add-oil-buddy\scripts\claim_log.txt`

**日志结果含义**：

| 关键字 | 含义 |
|---|---|
| `CLAIM_OK_PIXEL` | 领取成功 ✅ |
| `ALREADY_CLAIMED` | 今天已领过，正常跳过 ✅ |
| `CLAIM_UNVERIFIED` | 没确认成功，需人工看一眼 |
| `FAIL xxx` | 失败，把整行发给排查者 |

## 日常管理（直接对 WorkBuddy 说）

- 改时间：`把领积分任务改到每天 9 点`
- 暂停 / 恢复：`暂停领积分任务` / `恢复领积分任务`
- 删除：`删掉领积分的定时任务`
- 手动测：`现在手动跑一次领积分`（立即跑一遍，不弹倒计时）

## 前提与边界

- **平台**：仅 Windows（脚本依赖 Win32 接口），macOS / Linux 不适用。
- **WorkBuddy 客户端**：需已安装并登录；到点时客户端在运行。用内置定时任务正好满足这点。
- **输入设备**：不注入键盘；只在 WorkBuddy 窗口内移动鼠标点击，执行后鼠标归位，且有 5 分钟提醒窗供你反应。若你明确不希望接管鼠标，请不要安装。

## 常见问题

**Q：agent 说完全没有 Python？**
A：装 Python 3.8+，安装时勾选 "Add Python to PATH"，再把引导 prompt 重发一次。

**Q：pip 装 Pillow 失败（无网络 / 内网）？**
A：让 agent 用能联网的 Python，或手动 `python -m pip install Pillow -i <内网镜像>`，之后重跑第 2 步。

**Q：到点报 `FAIL no popup` 或找不到窗口？**
A：确认客户端已登录、窗口没缩到系统托盘。脚本启动会先清上一轮残留窗口，一般可自愈；持续失败再手动开一次客户端。

**Q：界面改版后不准了？**
A：脚本靠窗口位置推算坐标，客户端大改版后可能失准，需维护者跑 `buddy_station.py probe` 重新标定并同步进 skill。

## 给维护者

- 目录结构、脚本职责、automation 创建流程见 `SKILL.md`。
- `scripts/setup.py` 负责依赖自愈（`--ensure-deps`）、环境探测和参数生成；定时任务由 agent 通过 `automation_update` 创建，Python 无法自行创建。
- skill 内脚本是独立副本。主项目更新后需同步到 `scripts/` 并重打包：`package_skill.py <skill目录> <输出目录>`。
